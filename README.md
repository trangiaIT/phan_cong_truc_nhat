# On-call Schedule (Thứ 2 → Thứ 7) — 5 people

Trang web đơn giản để phân công ngày trực cho 5 người trong 6 ngày (Thứ Hai → Thứ Bảy).

Hướng dẫn sử dụng:
1. Mở `index.html` trong trình duyệt (double-click hoặc serve bằng static server).
2. Nhập tên 5 người vào các ô (hoặc để mặc định `Người 1`...`Người 5`).
3. Nhấn "Tạo lịch" để xem phân công.
4. Nhấn "Dịch (rotate)" để dịch vòng quay — hữu dụng khi bạn muốn lùi/đổi tuần.
5. Nhấn "Tải JSON" để xuất lịch ra file `schedule.json`.
